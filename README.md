# FORMA — прототип редактора canvas

Самостоятельный локальный стенд. React 19 + Vite, восемь секций, редактирование текста и пять сортируемых списков. Содержимое существует только в памяти страницы: обновление вкладки восстанавливает исходные данные. Серверных API, отправки изменений и браузерного хранилища нет.

## Опубликованная версия

- Стенд: https://canvas-prototype-plum.vercel.app/
- Приватный репозиторий: https://github.com/lesshishkin2/canvas-prototype
- Vercel: https://vercel.com/lesshishkin-gmailcoms-projects/canvas-prototype

Развёртывание выполнено через Vercel CLI. Автоматическая связь с приватным GitHub-репозиторием не установилась; автодеплой при push пока не настроен. Для публикации изменений из этой папки:

```bash
npm test
vercel deploy --prod --yes --scope lesshishkin-gmailcoms-projects
```

Настройки сборки заданы в `vercel.json`: `npm run build`, результат — `dist/client`. Локальная привязка `.vercel`, зависимости, артефакты сборки и `.env` исключены из Git. Материалы визуальной проверки исключены из загрузки Vercel через `.vercelignore`.

## Запуск

```bash
cd /Users/emilshagiev/code-local/sitebuilder-figma-audit/canvas-prototype
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

Открыть http://127.0.0.1:4173/ в Chrome. Поддерживаются ширины от 320 px, мышь, клавиатура и touch. Мобильная версия опубликована на Vercel. Пункты меню, подсказки и действия редактора — на английском.

На телефоне первый тап выбирает объект и показывает инструменты, второй отдельный тап по тому же тексту включает ввод. Done в верхнем баре завершает редактирование. Перенос — за ручку после движения на 6 px, без удержания; карточку за остальные части можно прокручивать. Выбор сохраняется при прокрутке. Светлые и тёмные кнопки canvas имеют размер 32 × 32 px; Edit block шире по тексту. Все действия секции показаны сразу, а при нехватке ширины группы переносятся на следующую строку. Верхнее ⋮ открывает Settings, Change theme, Preview. До 767 px блоки перестраиваются в одну колонку, на 768–1199 px карточки идут в две.

## Управление

- Кликните текст, чтобы редактировать его; подписи кнопок редактируются так же.
- Первый блок — компактное меню высотой 62 px с исходными подписями: логотип-картинка FORMA слева, пять ссылок в центре и кнопка-ссылка «Войти» справа. У логотипа доступны стандартные инструменты замены/редактирования изображения, у «Войти» — инструмент ссылки и редактирование текста. Отступы сверху и снизу — 8 px; панель секции намеренно перекрывает содержимое для проверки коллизий. У панели секции нет общей подложки: белые группы кнопок по краям, пустое пространство между ними пропускает указатель к содержимому. Длинные подписи и новые пункты могут увеличить высоту. Наведение на пункт, включая его текст, открывает общую панель: ссылка → копировать → удалить → ручка. Пункты можно переставлять по горизонтали и между строками. Клик редактирует подпись; иконка редактирования URL остаётся заглушкой.
- Enter добавляет перенос в обычном тексте, а в подписи кнопки/ссылки завершает ввод. Escape и клик вне поля завершают ввод, сохраняя введённое в памяти.
- Наведите на любую часть карточки или строки, чтобы открыть её панель. Порядок: изображение → ссылка → копировать/удалить → ручка drag.
- В блоке «Рассмотреть ближе» после коллекции — три карточки с обычными изображениями над текстом. На поле карточки доступны только копирование, удаление и ручка; на изображении — отдельные кнопки «Заменить» и «Редактировать» в центре изображения по обеим осям. Заголовки, подписи и описания редактируются. Изображение не является фоном, а карточка не моделирует ссылку.
- Следом расположен блок «Когда места мало» с тремя проверочными карточками: широкое изображение, миниатюра 180 × 72 без полей и ссылка у верхнего края. Наведите на картинку или ссылку, чтобы увидеть центрирование и смещение панели при коллизии. Карточки можно копировать, удалять и сортировать.
- Для перемещения тяните за значок четырёх направлений. Фиолетовая рамка показывает место вставки. У края окна работает автопрокрутка.
- Escape или отпускание за пределами исходного списка отменяет перенос. Между списками переносить нельзя.
- Последний элемент списка нельзя удалить или перемещать. Копия вставляется сразу после оригинала и редактируется независимо.
- Панели секции и карточки остаются при наведении на их содержимое. Дочерняя панель появляется у своего элемента; при пересечении опускается ниже родительской с зазором 6 px. Панели удерживаются при переходе через зазор. При вводе текста и drag все инструменты скрываются.
- Открытая панель карточки или изображения сохраняется в защитной области на 8 px сверху и справа — до края своего элемента. Через этот зазор можно медленно пройти к кнопкам поверх вложенной картинки.
- Появление и переключение hover-инструментов происходит после 150 мс на одной цели. При быстром проходе через вложенные элементы текущая панель сохраняется; фокус и ввод текста работают сразу. Закрытие после выхода задержано на 180 мс.
- Панели мягко проявляются и затухают за 125 мс, сохраняя позицию. Исчезающие инструменты уже не принимают клики. Возвращение во время исчезновения разворачивает fade; режим уменьшения анимации отключает переход.
- Панели кнопок, текстовых ссылок и пунктов меню расположены сверху справа. Возле верхнего бара они смещаются вниз, сохраняя выравнивание по правому краю.
- Верхний бар, действия секций, редактирование ссылок и изображения — заглушки с подсказками. Они не открывают диалоги и не выполняют переходы.
- Общей истории отмены нет. Нативная отмена ввода внутри текстового поля остаётся доступной.

Копирование и удаление сопровождаются короткой анимацией: соседи освобождают или занимают место, копия проявляется рядом с оригиналом, удалённый элемент затухает. При быстрых действиях движение продолжается из текущего положения. В reduced motion остаётся только fade; с клавиатуры изменения мгновенные. Кнопки дочерних инструментов, включая ручку, и белые кнопки секции — 32 × 32 px; слева расширенная по подписи Edit block с карандашом. Перед ручкой только отступ, без линии; подсказки центрируются под кнопкой и учитывают края окна.

## Устройство

Приёмы плавного взаимодействия, их параметры и сценарии проверки — в [UX-PATTERNS.md](UX-PATTERNS.md).

- `src/data.js` — исходный контент и операции над списками; идентификаторы копий создаются отдельно.
- `src/Editor.jsx` — централизованный ховер/выбор, поля текста, плавающие панели и оболочка редактора.
- `src/useCanvasTouch.js` — распознавание тапа, переключение способа ввода и touch-автопрокрутка.
- `src/viewport.js` — измеренная рабочая область, VisualViewport и видимость каретки.
- `src/EditorMenu.jsx` — меню мобильного бара и действий секции.
- `src/useCanvasMotion.js` — анимация структурных действий без изменения модели данных.
- `src/Tooltip.jsx` — общие подсказки с центрированием и ограничением видимой областью.
- `src/toolbar-layout.js` — размещение панелей с учётом родителей и границ окна.
- `src/App.jsx` — секции, карточки и сортировка через dnd-kit.
- `src/styles.css` — оформление страницы и инструментов.
- `public/assets` — локальные изображения и иконки. Шрифты Inter и Cormorant Garamond включаются из локальных пакетов Fontsource.

## Проверка

```bash
npm test
npm run build
```

Браузерные сценарии сохранены в `tests/browser-checks.js`. На свежезагруженной локальной странице выполнить в DevTools:

```js
await (await import("/tests/browser-checks.js")).runChecks();
await (await import("/tests/toolbar-motion-checks.js")).runToolbarMotionChecks();
await (await import("/tests/hierarchical-tools-checks.js")).runHierarchicalToolsChecks();
await (await import("/tests/edge-case-checks.js")).runEdgeCaseChecks();
```

Сценарии меняют демо-контент. После проверки перезагрузить страницу. Они проверяют отрисованный DOM, нативные операции ввода и события указателя, не обращаясь к внутреннему React state.

В мобильной эмуляции Chrome (320, 390, 430 и 768 px) на свежей странице можно выполнить:

```js
const mobile = await import("/tests/mobile-checks.js");
await mobile.runMobileChecks();
await mobile.runMobileEdgeChecks();
await mobile.runMobileDragChecks();
await mobile.runMobileAutoscrollCheck();
```

Touch-события в этих сценариях синтетические. Реальную экранную клавиатуру, нативные маркеры выделения, вставку из системного буфера и pinch нужно дополнительно проверить на Android Chrome и iOS Safari. Открытие меню, геометрия, выбор, ввод через DOM и логика переноса проверяются в эмуляции.

Результаты трёх размеров и визуальные материалы — в `evidence/`; вывод визуальной проверки — в `design-qa.md`.

## Источники

Исходная компоновка оболочки: редактор Site Builder и [Figma, node 25674:63938](https://www.figma.com/design/b2HwNFkDTvplokDelJjROK/is.art?node-id=25674-63938). Оформление инструментов обновлено: иконки панелей canvas — [Tabler Icons](https://tabler.io/icons) (`@tabler/icons-react`, MIT), цвета — пресеты [Gray из is.art](https://www.figma.com/design/b2HwNFkDTvplokDelJjROK/is.art?node-id=11770-27581). Прежние SVG удалены из приложения.

Редактирование изображения обозначено `PhotoEdit` (рамка картинки с карандашом), замена — `PhotoUp`, копирование — `CopyPlus`, перемещение — `ArrowsMove`. Иконки 16 px для мыши и 18 px для touch внутри кнопок 32 × 32 px; порядок действий и поведение не изменены. Основной фон — Gray/800, hover — Gray/700, нажатие — Gray/900, иконки — Gray/50, границы — Gray/600, недоступные иконки — Gray/500.

Фотографии загружены локально из тех же Unsplash-изображений, которые использовал предоставленный редактор: `photo-1579783902614-a3fb3927b6a5`, `photo-1541961017774-22349e4a1262`, `photo-1549289524-06cf8837ace5`, `photo-1531913764164-f85c52e6e654`, `photo-1460661419201-fd4cecdf8a8b`, `photo-1578321272176-b7bbc0679853`.

Имена художников, названия работ и программа — демонстрационный контент.

Верхний фиксированный бар сохраняет исходный дизайн: иконки Lucide, белый фон и фиолетовая кнопка Save Changes. Изменения оформления панелей canvas к нему не применяются.

Перемещение целых блоков работает за ручку **Drag block** в белой панели: порог 6 px, плавное смещение соседей, линия вставки и автопрокрутка. Escape или отпускание вне canvas отменяют перенос. Порядок блоков хранится только в памяти; вложенные карточки и пункты меню сортируются независимо.

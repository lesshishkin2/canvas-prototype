# FORMA — canvas-прототип

Прототип редактора на React + Vite для десктопа и мобильных устройств. Текст редактируется прямо на странице; элементы можно копировать, удалять и перетаскивать. Изменения хранятся в памяти и сбрасываются при перезагрузке. Редактирование ссылок и изображений показано без сохранения данных.

## Запуск

Нужны Node.js 22.12+ и npm. В папке проекта выполните:

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для проверки с телефона в той же сети: `npm run dev -- --host`.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Готовая статическая сборка — в `dist/client`. Браузерные сценарии находятся в `tests/`.

## Управление

- Мышь: клик по тексту включает ввод, наведение показывает инструменты.
- Touch: первый тап выбирает объект, следующий тап по тому же тексту включает ввод; **Done** завершает редактирование.
- Перетаскивание работает за ручку. Escape отменяет перенос. Последний элемент списка нельзя удалить.

Правила взаимодействия — в [UX-PATTERNS.md](UX-PATTERNS.md).

Изображения хранятся локально; Inter и Cormorant Garamond включаются в сборку через [Fontsource](https://fontsource.org/). Иконки — [Tabler](https://tabler.io/icons) и [Lucide](https://lucide.dev/).
